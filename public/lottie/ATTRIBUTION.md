## Replacement Notes
When replacing placeholder animations with downloaded assets:

1. Download from approved sources:
   - LottieFiles (https://lottiefiles.com) - Filter: Free, wedding/elegant
   - Lordicon (https://lordicon.com) - Search "envelope", "bird", "dove"
   - Rive Community (https://rive.app/community) - Search "bird flight", "envelope"
   - IconScout Lottie (https://iconscout.com/lotties) - Filter free

2. Validate each asset using `validate-assets.md` checklist

3. Update this file with:
   - Source URL
   - Author name
   - License type (CC0, Custom, etc.)
   - Attribution requirements (if any)

4. Replace the corresponding `.json` file in `public/lottie/`
